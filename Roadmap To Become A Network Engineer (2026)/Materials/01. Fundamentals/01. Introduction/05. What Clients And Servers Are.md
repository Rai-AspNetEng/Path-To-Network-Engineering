<h1>What Are Clients and Servers?</h1>

This concept is extremely important because you'll encounter it constantly.

<h2>Client</h2>

- A client requests a service or resource.

Examples:

```
Web browser
Mobile app
Email application
SSH client
FTP client
```

<h2>Server</h2>

- A server provides a service or resource.

Examples:

```
Web server
DNS server
DHCP server
File server
Database server
Email server
```

<h4>Example: Visiting a website</h4>

You open:

```
https://example.com
```

Your browser is the:

```
CLIENT
```

The computer hosting the website is the:

```
SERVER
```

Conceptually:

```
┌────────────┐
│   Client   │
│  Browser   │
└─────┬──────┘
      │
      │ Request
      ▼
┌────────────┐
│   Server   │
│ Web Server │
└─────┬──────┘
      │
      │ Response
      ▼
   Web Page
```

<h2>Client-Server Communication</h2>

Suppose you open YouTube.

- Your device might communicate with several services.

Simplified:

```
Your PC
   │
   ├── DNS request
   │
   ▼
DNS Server
   │
   └── IP address
          │
          ▼
     YouTube servers
          │
          ▼
     Video/content
```

In reality, modern applications are much more complicated, involving many servers, CDNs, APIs, load balancers, databases, and other infrastructure.

But this basic model is essential.
