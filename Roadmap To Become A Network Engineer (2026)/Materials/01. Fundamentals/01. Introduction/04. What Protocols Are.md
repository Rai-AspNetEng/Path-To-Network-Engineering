<h1>What Are Protocols?</h1>

This is another fundamental concept.

- A protocol is essentially a <b>set of rules that devices follow to communicate.</b>

Image two people communicating:

```
Person A ─────── Person B
```

They need to agree on:

- What language to use
- How messages begin
- How messages end
- How information is formatted
- What happens if something is missing
- How responses are sent

Computers need the same thing.

---

<h2>Example of network protocols</h2>

<h4>1. HTTP (HyperText Transfer Protocol) or HTTPS (HyperText Transfer Protocol Secure)</h4>

- Used for web communication.

```
Browser ── HTTP/HTTPS ── Web Server
```

<h4>2. DNS (Domain Name System)</h4>

- Converts names into IP Addresses.

```
google.com
     ↓
DNS
     ↓
142.x.x.x
```

<h4>3. DHCP (Dynamic Host Configuration Protocol)</h4>

- Automatically provides network configuration.

```
PC ── DHCP ── Router/DHCP Server
```

It can provide:

```
IP address
Subnet mask
Default gateway
DNS server
```

<h4>4. TCP (Transmission Control Protocol)</h4>

- Provides reliable, connection-oriented communication.

<h4>5. UDP (User Diagram Protocol)</h4>

- Provides connectionless communication with less overhead.

<h4>6. IP (Internet Protocol)</h4>

- Provides logical addressing and routing.

---

<h2>Why Are Protocols Necessary?</h2>

Imagine your send:

```
Hello
```

to another computer.

The receiving computer needs to know:

```
What is this?
```

Is it:

```
HTTP?
DNS?
SSH?
FTP?
Email?
Something else?
```

Protocols define how information should be structured and interpreted.

That's why networking isn't just:

```
"Plug cable → data magically travels."
```

There are layers of rules and processes involved.
