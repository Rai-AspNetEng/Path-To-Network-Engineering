<h1>What are LANs and WANs?</h1>

- Think of a LAN as a local conversation inside a room, while a WAN is a global telephone network connecting different cities.

<h2>LAN (Local Area Network)</h2>

- A LAN is a network covering a relatively small geographic area.

Examples:

- Home
- Classroom
- Computer Laboratory
- Office
- Building

Example:

```
              LAN
┌─────────────────────────────┐
│                             │
│ PC ──┐                      │
│      │                      │
│ PC ──┼── Switch             │
│      │                      │
│ PC ──┘                      │
│                             │
│ Printer                     │
└─────────────────────────────┘
```

All these devices belong to the local network.

<h2>WAN (Wide Area Network)</h2>

- A WAN connects networks across larger geographic areas.

For example:

```
MANILA OFFICE
     │
     │
    WAN
     │
     │
CEBU OFFICE
```

Or:

```
Company HQ
     │
     ├──────── WAN ──────── Branch 1
     │
     ├──────── WAN ──────── Branch 2
     │
     └──────── WAN ──────── Branch 3
```

The Internet is the world's largest example of an interconnected network of networks.

---

<h2>LAN VS WAN</h2>

```
| Feature            | LAN               | WAN                                  |
| ------------------ | ----------------- | ------------------------------------ |
| Area               | Small             | Large                                |
| Example            | Office            | Office-to-office                     |
| Typical ownership  | Organization/home | Multiple providers                   |
| Speed              | Usually high      | Varies                               |
| Latency            | Usually lower     | Usually higher                       |
| Example technology | Ethernet          | MPLS, Internet, leased lines, SD-WAN |

```

Don't think:

```
LAN = Ethernet
WAN = Internet
```

It's more nuanced than that.

LAN and WAN describe scope/architecture, while Ethernet, Wi-Fi, MPLS, etc. describe technologies used to implement networks.
