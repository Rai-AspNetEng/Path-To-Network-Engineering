<h1>What Are Network Devices?</h1>

- Network devices are hardware or virtual components that participate in network communication.

The most important ones for beginners are:

```
| Device       | Main purpose                           |
| ------------ | -------------------------------------- |
| NIC          | Connects a device to a network         |
| Switch       | Connects devices within a LAN          |
| Router       | Connects different networks            |
| Access Point | Provides Wi-Fi connectivity            |
| Firewall     | Controls/filters traffic               |
| Modem/ONT    | Connects to an ISP's access technology |
| Server       | Provides services/resources            |
| Client       | Requests services/resources            |
```

Let's go through the important ones.

<h2>Network Interface Card (NIC)</h2>

- A Network Interface Card (NIC) is the component <b>that allows a device to connect to a network.</b>

For example:

```
Laptop
┌──────────────────┐
│ CPU              │
│ RAM              │
│ Storage          │
│                  │
│ NIC ─────────────┼── Ethernet
└──────────────────┘
```

<h3>Wired Connectivity</h3>

```
PC ───────── Ethernet ───────── Switch
```

<h3>Wireless Connectivity</h3>

```
Laptop ))))) Wi-Fi ))))) Access Point
```

- A NIC has a MAC address used for communication at the Data Link layer.

Example:

```
MAC Address:

00:1A:2B:3C:4D:5E
```

<h2>What Is a Switch?</h2>

- A switch connects devices within a network, usually a LAN.

For example:

```
             Switch
          ┌────┼────┐
          │    │    │
         PC1  PC2  PC3
```

The switch receives Ethernet frames and forwards them toward the appropriate destination.

<h3>Why Do We Need Switches?</h3>

- Imagine an office with 100 computers.

You could theoretically try to connect everything directly:

```
PC1 ───── PC2
 │  ╲     │
 │   ╲    │
PC3 ───── PC4
```

That becomes messy very quickly.

Instead:

```
             Switch
       ┌──────┼──────┐
       │      │      │
      PC1    PC2    PC3
```

The switch gives you a centralized way of connecting devices.

<h3>Why Does A Switch Know?</h3>

- A switch build a MAC Address table.

For example:

```
MAC Address          Port
-------------------------
AA:AA:AA:AA:AA:AA    Fa0/1
BB:BB:BB:BB:BB:BB    Fa0/2
CC:CC:CC:CC:CC:CC    Fa0/3
```

So if a frame is destined for:

```
BB:BB:BB:BB:BB:BB
```

The switch knows:

- "That device is connected to Fa0/2."

Therefore it forwards the frame there.

This is one of the first concepts you should eventually understand deeply.

<h2>What Is a Router?</h2>

- A router connects different networks.

This distinction is extremely important:

```
Note: Switches primarily connect devices within networks. Routers connect networks to other networks.
```

For example:

```
Network A
192.168.1.0/24

PC ──┐
PC ──┼── Switch ── Router
PC ──┘              │
                    │
                    ▼
              Network B
              10.0.0.0/24
```

The router provides a path between:

```
192.168.1.0/24
        ↕
     Router
        ↕
10.0.0.0/24
```

<h2>Router Example: Your Home</h2>

- Your home netwrok might look conceptually like:

```
              INTERNET
                  │
                  │
                ISP
                  │
                  ▼
             ┌─────────┐
             │ Router  │
             └────┬────┘
                  │
        ┌─────────┼─────────┐
        │         │         │
       PC       Phone       TV
```

Your router essentially connects:

```
HOME NETWORK
     ↕
   ROUTER
     ↕
INTERNET
```

This is one of the most important mental models in networking.
