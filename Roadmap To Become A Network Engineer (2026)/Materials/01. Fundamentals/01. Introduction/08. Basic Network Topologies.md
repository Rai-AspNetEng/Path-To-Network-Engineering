<h1>Basic Network Devices</h1>

- They are physical hardware tools that connect computers, phones, and other gadgets so they can talk to each other and share an internet connection. They act like postal workers or road signs for digital data, making sure information gets from one place to another.

Here some samples:

<h3>01. Router</h3>

- Connects different networks.

```
LAN ── Router ── WAN/Internet
```

<h3>02. Switch</h3>

- Connects devices within a LAN.

```
PC ─┐
PC ─┼── Switch
PC ─┘
```

<h3>03. Firewall</h3>

- Controls traffic according to security rules.

For example:

```
Internet
   │
   ▼
Firewall
   │
   ▼
Internal Network
```

It might say:

```
Allow HTTPS → YES
Allow SSH from Internet → NO
Allow internal traffic → DEPENDS
```

By studying Network Security, you'll be able to have a solid foundation with Firewalls.

<h3>04. Wireless Access Point</h3>

Provides a wireless network access.

```
          Access Point
          /    |    \
       Laptop Phone Tablet
```

It essentially bridges wireless devices into the network.

<h3>05. Modem/ONT</h3>

These devices connect your network to an ISP's access technology.

For example, fiber internet commonly uses an ONT/ONU.

Simplified:

```
Fiber
  │
  ▼
 ONT
  │
  ▼
Router
  │
  ▼
LAN
```
<h3>06. Server</h3>

Provides services.

Examples:
```
- Web Server
- DNS Server
- DHCP Server
- File Server
- Database Server
- Authentication Server
```

<h3>07. Client</h3>

Consumes services.

Examples:

```
- Laptop
- Desktop
- Phone
- Tablet
- Application
```

<h2>Putting Everyting Together</h2>

Here's a simple network you should be able to understand after completi this introduction:

```
                       INTERNET
                           │
                           │
                          ISP
                           │
                           ▼
                    ┌─────────────┐
                    │   Router    │
                    └──────┬──────┘
                           │
                    ┌──────▼──────┐
                    │   Switch    │
                    └───┬───┬───┬─┘
                        │   │   │
                       PC  PC Printer
                        │
                        │
                    Access Point
                      )))  )))
                    Laptop Phone
```

Now imagine you open a website.

Something like this happens conceptually:

```
Laptop
   │
   │ Wi-Fi
   ▼
Access Point
   │
   ▼
Switch
   │
   ▼
Router
   │
   ▼
ISP
   │
   ▼
Internet
   │
   ▼
Web Server
```

And many protocols participate along the way:

```
Wi-Fi / Ethernet
       ↓
      ARP
       ↓
       IP
       ↓
      TCP
       ↓
     HTTPS
```

Don't worry if <b>ARP</b>, <b>IP</b>, <b>TCP</b>, and <b>HTTPS</b> aren't completely clear yet.

You'll learn each one later.

<h2>A Very Important Mental Model</h2>

- As you progress toward network engineering, start thingking about networking in layers.

When someone says:

```
"The Internet isn't working."
```

Don't immediately think:

```
"The router is broken."
```

Instead, start asking:

```
Is the physical connection working?
          ↓
Is the NIC working?
          ↓
Does the device have an IP address?
          ↓
Is the subnet correct?
          ↓
Is the default gateway correct?
          ↓
Can I reach the gateway?
          ↓
Can I reach another network?
          ↓
Does DNS work?
          ↓
Does the application work?
```

This mindset is much more important than memorizing commands.
