<h1>Basic Network Architecture</h1>

Network architecture is essentially:

- How the components of a network are organized and how they interact.

For example:

```
                    INTERNET
                        │
                        ▼
                  ┌──────────┐
                  │ Firewall │
                  └────┬─────┘
                       │
                    Router
                       │
              ┌────────┴────────┐
              │                 │
           Switch             Switch
              │                 │
        ┌─────┼─────┐     ┌─────┼─────┐
       PC    PC   Printer  PC   Server  AP
```

This is a network architecture.

You need to understand:

- What devices exist?
- Where are they located?
- What connects to what?
- Which devices communicate?
- Where does traffic go?
- Where are security controls?
- How does the network reach the Internet?

<h2>Basic Network Architecture: A Small Office</h2>

Let's create a realistic beginner example.

Imagine a company with:

- 20 employees
- 1 server
- Wi-Fi
- Internet access
- Printer

A simplified network might look like:

```
                         INTERNET
                             │
                             │
                           ISP
                             │
                             ▼
                       ┌──────────┐
                       │ Firewall │
                       └────┬─────┘
                            │
                         Router
                            │
                       ┌────┴────┐
                       │  Switch │
                       └────┬────┘
                            │
          ┌─────────────────┼──────────────────┐
          │                 │                  │
         PCs              Server             Printer
                                             │
                                        Access Point
                                             ))) 
                                           Wi-Fi
```

Now think like a network engineer.

You should be able to ask:

```
What connects the PCs?

- The switch.
```

```
What connects the office to the Internet?

- The router/firewall/ISP connection.
```

```
What provides Wi-Fi?

- The access point.
```

```
What provides services?

- The server.
```

```
What controls traffic?

- The firewall/router.
```

That's the level of understanding you should develop in this folder.
