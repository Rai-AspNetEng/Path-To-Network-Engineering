<h1> What is Computer Networking></h1>

- Computer networking is the practice of connecting computers and other devices so they can communication and exchange data.

A network can be extremely small: 

```
Laptop ─── Printer
```

Or extremely large:

```
Your PC
   │
   ▼
Home Router
   │
   ▼
ISP
   │
   ▼
Internet
   │
   ▼
Google / YouTube / GitHub / Cloud Server
```

- So, its main purpose/objective is to allow multiple devices to communicate and share resources.

What can devices share?

<h2>Networks allow devices to share:</h2>

- Files
- Printers
- Internet access
- Applications
- Databases
- Websites
- Servers
- Storage
- Voice/video
- Security services
- Cloud resources

For example, imagine your university has:

```
              INTERNET
                  │
                  ▼
             ┌─────────┐
             │ Router  │
             └────┬────┘
                  │
          ┌───────┴────────┐
          │                │
       Switch           Switch
          │                │
     ┌────┼────┐      ┌────┼────┐
     PC    PC   PC    PC   Printer Server
```

All of these devices can communicate because they're connected through a network.

<h2>Core Parts of a Network:</h2> 

1. <b>Nodes:</b>Devices like PCs, phones, servers, and printers that send or get data.
2. <b>Links:</b> The physical wires (like Ethernet or fiber optics) or wireless signals (like Wi-Fi) connecting the nodes.
3. <b>Routers:</b> Hardware that directs data traffic between different networks, such as your home network and the internet.
4. <b>Switches:</b> Devices that connect multiple computers inside a single local network.
5. <b>Protocols:</b> The shared rules and languages (like TCP/IP) that let different machines understand each other.
