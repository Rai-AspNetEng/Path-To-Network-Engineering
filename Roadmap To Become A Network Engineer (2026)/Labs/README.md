# Labs — Hands-on Exercises

This folder contains step-by-step lab exercises to practice the core topics in the roadmap. Each lab includes goals, topology, commands, and verification steps.

Labs included:
- Lab 1 — Subnetting and IP planning
- Lab 2 — VLANs and basic switching
- Lab 3 — OSPF routing lab
- Lab 4 — Site-to-site VPN (IPSec) basic setup
- Lab 5 — Network automation: Ansible playbook for backups

Use GNS3/EVE‑NG/VirtualBox or Packet Tracer to run these labs.
