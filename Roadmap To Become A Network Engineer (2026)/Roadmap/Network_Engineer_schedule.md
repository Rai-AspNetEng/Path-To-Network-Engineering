# Network Engineer — 24-Week Study Schedule

Overview: 24-week plan (approx. 6 months) assuming ~8–12 hours/week. Adjust pace to your availability.

Weeks 1–4: Foundations
- Week 1: Core concepts, OSI vs TCP/IP, MAC vs IP
- Week 2: Ethernet frames, switching basics, basic CLI commands
- Week 3: DNS, DHCP, ports, sockets; start subnetting practice
- Week 4: Small topology lab (2 hosts + switch + router)

Weeks 5–8: Addressing & Switching
- Week 5: IPv4 addressing, CIDR, private/public ranges
- Week 6: VLSM and summarization practice
- Week 7: VLANs, trunking, STP theory
- Week 8: Build VLAN lab and inter-VLAN routing

Weeks 9–12: Routing
- Week 9: Static routes, default gateway, routing tables
- Week 10: OSPF single-area fundamentals and practice
- Week 11: BGP concepts, path selection, basic neighbor setup
- Week 12: Routing lab: OSPF + a simple BGP scenario

Weeks 13–16: WAN, VPNs & High Availability
- Week 13: NAT types, DHCP server behavior
- Week 14: Site-to-site VPN concepts (IPSec), GRE basics
- Week 15: HA: HSRP/VRRP/GLBP and load balancing concepts
- Week 16: VPN + HA combined lab

Weeks 17–20: Wireless, Security & Troubleshooting
- Week 17: Wi‑Fi standards, RF basics, site survey intro
- Week 18: Firewalls, ACLs, IDS/IPS overview
- Week 19: Troubleshooting toolkit: ping, traceroute, tcpdump, Wireshark
- Week 20: Security lab: firewall rules and capture analysis

Weeks 21–24: Cloud, Automation & Observability
- Week 21: Cloud networking basics (VPC/VNet), cloud VPN
- Week 22: Ansible basics for networking, simple playbooks
- Week 23: Monitoring basics (SNMP, NetFlow), set up Prometheus/Grafana demo
- Week 24: Capstone project: design + deploy mini network (cloud or emulated), automate a task, add monitoring

Tips:
- Lab time > passive reading — aim for 60–70% hands-on.
- Capture packet traces during labs and review with Wireshark.
- Keep a lab journal with commands and results.
