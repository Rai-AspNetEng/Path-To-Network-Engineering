<h1>Test Your Knowledge: Computer Architecture</h1>

1. What does the hardware layer in computer architecture include?

- <b>The physical components of a computer</b>
- Software applications 
- How the computer is maintained, operated, and programmed 
- Operating system  

These are objects you can physically hold. Laptops, phones, monitors, keyboards, etc.

2. What are the four main layers of computer architecture? 

- <b>Hardware, Operating System, Software, User</b> 
- Binary, Hardware, Operating System, Software 
-Computer, Operating System, Software, User 
-Hardware, Windows, Software, User 

The layers of computer architecture are the hardware, operating system, software, and user layers.

3. What is the purpose of the software layer in computer architecture?

- It is the physical components of a computer.
- <b>It allows humans to interact with computers.</b> 
- It allows hardware to communicate with the system.
- It operates, maintains, and programs the computer. 

4. What’s a critical aspect of working as an IT support professional?

- Building computers 
- Understanding how operating systems work 
- Designing and creating complex programs 
- <b>The human element</b>

While IT professionals work with computers every day, it is the user interaction that makes up most of their job, from responding to user emails to troubleshooting computers.
