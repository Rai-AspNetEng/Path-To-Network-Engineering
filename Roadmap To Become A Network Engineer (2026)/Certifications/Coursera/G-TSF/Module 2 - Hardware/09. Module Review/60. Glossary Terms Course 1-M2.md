<h1>Glossary terms from course 1, module 2</h1>

<h4>New terms and their definitions:</h4>

1. <b>Address bus:</b> Connects the CPU to the MCC and sends over the location of the data, but not the data itself

2. <b>ATA:</b> The most common interface that hard drives use to connect to our system

3. <b>ATX (Advanced Technology eXtended):</b> The most common form factor for motherboards

4. <b>Backward compatible:</b> It means older hardware works with newer hardware

5. <b>Bios (Basic Input Output Services):</b> The BIOS is software that helps initialize the hardware in our computer and gets our operating system up and running

6. <b>BYOD (Bring Your Own Device):</b> Refers to the practice of allowing people to use their own personal devices for work

7. <b>Cache:</b> The assigned stored location for recently or frequently accessed data; on a mobile app it is where anything that was changed or created with that app is stored

8. <b>Charge cycle:</b> One full charge and discharge of a battery

9. <b>Chipset:</b> It decides how components talk to each other on our machine

10. <b>Clock cycle:</b> When you send a voltage to the clock wire

11. <b>Clock speed:</b> The maximum number of clock cycles that it can handle in a set in a certain time period

12. <b>Clock wire:</b> When you send or receive data, it sends a voltage to that clock wire to let the CPU know it can start doing calculations

13. <b>CPU:</b> Central processing unit

14. <b>CPU sockets:</b> A CPU socket is a series of pins that connect a CPU’s processor to the PC’s motherboard

15. <b>Data sizes:</b> Metrics that refer to data sizes including bit, byte, kilobyte, kibibyte, and megabyte

16. <b>DDR SDRAM (Double Data Rate SDRAM):</b> A type of RAM that is faster, takes up less power, and has a larger capacity than earlier SDRAM versions

17. <b>Desktop:</b> The main screen where we can navigate our files, folders, and applications

18. <b>DIMM:</b> Dual Inline Memory Module

19. <b>Display port:</b> Port which also outputs audio and video

20. <b>DRAM:</b> Dynamic Random Access Memory

21. <b>Drivers:</b> The drivers contain the instructions our CPU needs to understand external devices like keyboards, webcams, printers

22. <b>DVI:</b> DVI cables generally just output video

23. <b>Electrostatic discharge:</b> Electrostatic discharge is a sudden and momentary flow of electric current between two electrically charged objects caused by contact, an electrical short or dielectric breakdown

24. <b>External Data Bus (EDB):</b> It's a row of wires that interconnect the parts of our computer

25. <b>Factory reset:</b> Resetting a device to the settings it came with from the factory

26. <b>Form factor:</b> A mathematical way to compensate for irregularities in the shape of an object by using a ratio between its volume and height

27. <b>Hard drive:</b> It is a long term memory component that holds all of our data, which can include music, pictures, applications

28. <b>Hardware:</b> External or internal devices and equipment that help you perform major functions

29. <b>HDD (Hard disk drive):</b> Hard disk drives, or HDDs, use a spinning platter and a mechanical arm to read and write information

30. <b>HDMI:</b> A type of cable that outputs both video and audio

31. <b>Heatsink:</b> It is used to dissipate heat from our CPU

32. <b>Instruction set:</b> A list of instructions that our CPU is able to run

33. <b>ITX (Information Technology eXtended):</b> A form factor for motherboards that is much smaller than ATX boards

34. <b>Land Grid Array (LGA):</b> It is a type of CPU socket that stick out of the motherboard

35. <b>Lightning adaptor:</b> One of the standard power, data and display connector types used in mobile devices

36. <b>Mb/s:</b> megabit per second, which is a unit of data transfer rate

37. <b>Memory controller chip (MCC):</b> A bridge between the CPU and the RAM

38. <b>Micro display port:</b> One of the standard power, data and display connector types used in mobile devices

39. <b>Micro HDMI:</b> One of the standard power, data and display connector types used in mobile devices

40. <b>Micro USB:</b> One of the standard power, data and display connector types used in mobile devices

41. <b>Mini HDMI:</b> One of the standard power, data and display connector types used in mobile devices

42. <b>Mini USB:</b> One of the standard power, data and display connector types used in mobile devices

43. <b>Motherboard:</b> The body or circulatory system of the computer that connects all the pieces together

44. <b>Northbridge:</b> interconnects stuff like RAM and video cards

45. <b>NVMe (NVM Express):</b> interface standard which allows greater throughput of data and increased efficiency

46. <b>Overclocking:</b> it increases the rate of your CPU clock cycles in order to perform more tasks

47. <b>PCI Express:</b> Peripheral Component Interconnect Express

48. <b>Peripherals:</b> the external devices which we connect to our computer that add functionality, like: a mouse, a keyboard, and a monitor

49. <b>Pin Grid Array (PGA):</b> CPU socket where the pins are located on the processor itself

50. <b>Ports:</b> Connection points that we can connect devices to that extend the functionality of our computer

51. <b>POST (Power On Self Test):</b> It figures out what hardware is on the computer

52. <b>Power supply:</b> Converts electricity from our wall outlet onto a format that our computer can use

53. <b>Programs:</b> Basic instructions that tell the computer what to do

54. <b>RAM:</b> Random Access Memory

55. <b>Registers:</b> An accessible location for storing the data that our CPU works with

56. <b>Reimaging:</b> The process of reimaging involves wiping and reinstalling an operating system using a disk image which is a copy of an operating system

57. <b>Return merchandise authorization (RMA):</b> The process of receiving returned merchandise and authorizing a refund

58. <b>ROM chip (Read Only Memory):</b> A read-only memory chip where the BIOS is stored

59. <b>RPM:</b> Revolutions per minute

60. <b>Safe operating temperature:</b> The temperature range in which rechargeable batteries must be kept in order to avoid damage

61. <b>SATA:</b> The most popular serial ATA drive, which uses one cable for data transfers

62. <b>SDRAM:</b> It stands for Synchronous DRAM, this type of RAM is synchronized to our systems' clock speed allowing quicker processing of data

63. <b>SOC (System On a Chip):</b> Packs the CPU, Ram, and sometimes even the storage onto a single chip

64. <b>Southbridge:</b> It maintains our IO or input/output controllers, like hard drives and USB devices that input and output data

65. <b>SSD:</b> Solid State Drive

66. <b>Standoffs:</b> Used to raise and attach your motherboard to the case

67. <b>Thermal paste:</b> A substance used to better connect our CPU and heat sink, so the heat transfers from to the other better

68. <b>Type-C connector:</b> A type of USB connector meant to replace many peripheral connections

69. <b>UEFI:</b> Unified Extensible Firmware Interface

70. <b>USB (Universal Serial Bus):</b> A connection standard for connecting peripherals to devices such as computers

71. <b>USB-C adapter:</b> One of the standard power, data and display connector types used in mobile devices
